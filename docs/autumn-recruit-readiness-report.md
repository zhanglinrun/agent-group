# 秋招项目验收报告

## 结论

本轮已把项目验收到“可运行、可演示、可测试、可复述”的状态。项目主线仍然是“学术 `Agent`（智能体）平台 + 额度交易一致性系统”，不是普通聊天机器人，也不是单纯支付项目。

## 验证结果

- 后端测试：`cd backend && mvn -pl agent-group-app -am test`（运行应用模块及依赖测试）通过，355 个测试，0 失败，0 跳过。
- 后端编译：`cd backend && mvn clean compile`（全量编译）通过。
- 前端测试：`cd frontend && npm test`（前端测试）通过，22 个测试文件，149 个测试。
- 前端构建：`cd frontend && npm run build`（前端生产构建）通过。

## 浏览器验收

- 用户端首页、运营后台、图像工作区、数据问答工作区、`MRAG`（多模态检索增强生成）工作区和交易工作区均可直达打开，无白屏和错误覆盖层。
- 工作台顶部已接回 `Agent`（智能体配置）和 `MCP`（模型上下文协议）入口。
- `MCP`（模型上下文协议）面板能展开，能显示服务、工具、健康检查和授权入口；当前没有注册外部服务时显示未配置状态。
- 页面内图像生成已验证成功，返回 `provider=local-fallback-renderer`（本地降级渲染器）、`usedFallback=true`（使用降级），并能直接显示生成图片缩略图。

## 接口验收

- 普通对话链路已复验，`SSE`（服务器推送事件）返回 `run_start`（运行开始）、`plan_delta`（计划增量）、`flow_delta`（流程增量）、`answer_delta`（回答增量）、`quota_delta`（额度变化）和 `done`（完成）事件。
- `Skill`（技能）链路已复验，`SSE`（服务器推送事件）返回 `run_start`（运行开始）、`plan_delta`（计划增量）、`flow_delta`（流程增量）、`tool_call`（工具调用）、`tool_result`（工具结果）、`answer_delta`（回答增量）和 `done`（完成）事件。
- 生图接口 `POST /api/v1/academic/workspace/image/generate`（图像生成接口）当前返回 `0000`（成功），产物为 `data:image/png;base64`（内联图片）。
- 后台订单接口能展示中文交易状态，例如“已支付，额度已到账”“拼团已关闭，未发放额度”“交易完成，额度已到账”。
- 演示用户额度摘要可查，当前余额为 57.08 点，最近流水类型为 `TASK_CONSUME`（任务消耗）。

## 支付沙箱限制

当前官方支付宝沙箱仍未就绪，这是外部配置限制，不是代码伪通过。接口返回缺失项：

- `AGENT_GROUP_ALIPAY_APP_ID`（支付宝应用编号）
- `AGENT_GROUP_ALIPAY_PRIVATE_KEY`（支付宝应用私钥）
- `AGENT_GROUP_ALIPAY_PUBLIC_KEY`（支付宝公钥）
- `PUBLIC_AGENT_GROUP_ALIPAY_NOTIFY_URL`（公网支付回调地址）

`MOCK_PAY`（模拟支付）当前明确标记为 `TEST_ONLY`（仅测试），不能作为生产支付能力展示。

## 本轮补强

- 修复工作区直达路由，`/workspace/data`（数据工作区）、`/workspace/mrag`（多模态检索工作区）、`/workspace/trade`（交易工作区）不再回落到普通对话工作区。
- 统一交易展示状态，区分“支付成功，等待成团”和“额度已到账”。
- 增加后台按订单补发额度入口，但仍只按后端订单状态发放额度。
- 增加本地降级生图端口，外部生图服务缺失时仍能演示图像工作区，同时明确标记降级来源。
- 修复本地降级图片的前端预览，安全放行 `data:image`（图片内联地址），继续拒绝危险协议。
- 接回 `Agent`（智能体配置）和 `MCP`（模型上下文协议）管理面板入口。

## 面试可讲亮点

- 交易事实和模型回答分离：余额、到账、退款和拼团状态只能来自后端交易系统。
- 额度发放规则清晰：直购支付成功可到账，拼团支付成功不等于到账，必须成团或交易完成后才发放。
- `Agent`（智能体）运行可回放：计划、工具调用、结果、产物和额度消耗都能追踪。
- 外部依赖可解释：支付宝沙箱、外部模型、外部生图服务未配置时，有明确检查结果和降级状态。

## 剩余风险

- 官方支付宝沙箱还需要真实密钥和公网回调地址后才能做生产级支付联调。
- `MCP`（模型上下文协议）当前没有接入外部服务，面试演示时只能展示管理面板和未配置状态。
- 真实外部模型质量、真实外部生图质量和公网支付回调稳定性，需要在密钥和公网环境齐全后再验收。
