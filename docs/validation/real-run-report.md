## 验收步骤

1. 启动本地依赖和后端。
2. 上传商品详情、活动规则、售后政策三类文档。
3. 执行导购问题，确认返回知识依据、商品卡片和 `decisionId`（导购决策编号）。
4. 使用 `decisionId`（导购决策编号）发起拼团锁单。
5. 创建支付单并发送支付回调。
6. 执行 50 条评测用例。
7. 打开 `Grafana`（指标看板工具）记录关键指标。
