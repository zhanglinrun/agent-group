# PPT Agent 工作流

模拟人类专家团队的 AI PPT 生成系统。核心理念：**PPT的灵魂是内容，先内容后设计。**

## 工作流

```
用户输入主题 → 需求调研 → 大纲规划 → 资料检索 → 策划稿 → SVG生成
```

## 快速启动

用户给出主题后，按以下顺序执行：

### Step 1: 需求调研
1. 用 `multi-search-engine` 或 `online-search` 搜索主题资料
2. 像顾问一样问用户 3-5 个关键问题（受众/目的/页数/风格/已有素材）
3. **不要急着生成**，先把需求聊透

详细提问模板：读取 `references/01_requirement_research.md`

### Step 2: 大纲规划
1. 用金字塔原理构建逻辑结构
2. 输出结构化 JSON 大纲（cover → toc → parts → end_page）
3. **展示给用户确认**，可调整增删

详细提示词：读取 `references/02_outline_planning.md`

### Step 3: 资料检索
1. 遍历大纲每个页面标题，搜索整理资料
2. 每个页面形成"资料包"（关键事实+数据+引用）
3. 数据要有来源，不编造

详细提示词：读取 `references/03_research.md`

### Step 4: 策划稿（关键差异化步骤）
1. 为每一页规划版式和元素布局
2. 从 Bento Grid 布局中选择合适组合
3. 生成简朴的页面初稿，**展示给用户确认**

详细提示词：读取 `references/04_planning_draft.md`

### Step 5: SVG 设计生成
1. 基于策划稿逐页生成 SVG 文件
2. 画布：`viewBox="0 0 1280 720"`
3. 使用 Bento Grid 卡片式布局，保持视觉一致性
4. 保存到 `{workspace}/ppt-output/{主题}/`

SVG 模板和配色方案：读取 `references/05_svg_generation.md`

## Bento Grid 布局速查

| 内容类型 | 布局 | 说明 |
|---------|------|------|
| 单一核心观点 | 单一焦点 | 一张大卡片，视觉冲击 |
| 两个并列要点 | 两栏 | 50/50 或 2/3+1/3 |
| 三个并列要点 | 三栏 | 等宽卡片 |
| 主要点+辅助 | 主次结合 | 大居中+两侧小卡片 |
| 数据+图表+文字 | 混合网格 | 自由组合 |

## 配色方案

预设 5 套，用户可选：商务蓝 / 科技紫 / 自然绿 / 活力橙 / 暗夜黑。详见 `references/05_svg_generation.md`。

## 注意事项

- 每一步都让用户确认，不要一口气跑完
- 资料要真实，注明来源
- 风格统一，整套PPT一致的配色和字体
- SVG 文件使用 UTF-8 编码
