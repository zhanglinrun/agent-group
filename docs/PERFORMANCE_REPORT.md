## 💰 成本优化

### LLM 调用优化
- **任务分析**: 从 LLM → 规则，节省每次调用
- **重规划**: 仅在必要时调用 LLM
- **预估节省**: 每次执行减少 1-2 次 LLM 调用，成本降低 20%

### 执行效率优化
- **智能重规划**: 复用 70% 已完成步骤，避免重复执行
- **模式动态切换**: 选择最优模式，减少不必要的复杂执行
