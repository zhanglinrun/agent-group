# 学习平板营销活动规则

轻薄学习平板标准版支持 3 人拼团。拼团活动开始后，用户可以先锁定拼团名额，再创建支付单。支付成功后，订单进入已支付状态，系统等待拼团结算。

标准版原价 2399 元，拼团价 2099 元。直接购买按原价支付，不占用拼团名额；拼团购买按拼团价锁单，成团后订单进入已成团状态。

高配创作平板支持 5 人拼团。高配版原价 3299 元，拼团价 2899 元，适合预算更充足、需要创作性能的用户。

拼团锁单必须带幂等键。重复锁单时，系统返回已有锁单和订单结果，不重复占用名额。支付回调和成团结算也要幂等处理，避免重复更新订单状态。

活动过期、商品下架或拼团队伍已满时，系统不能继续生成可购买入口，只能提示用户选择直接购买或等待新活动。

## 活动风控规则

同一用户同一活动只允许保留一个有效锁单。锁单成功但未支付时，订单状态为待支付；支付成功后，订单状态为已支付；达到成团人数后，订单状态才可以变为已成团。

拼团价只适用于拼团购买入口。用户选择直接购买时，不能把拼团价作为应付金额。

导购回答中出现购买建议时，商品卡片、回答文字和订单金额必须保持一致。

导购推荐进入下单入口前必须生成导购报价凭证，凭证内部包含导购决策编号、商品、活动、报价和有效期。下单时后端必须重新校验凭证，订单金额要和商品卡片、支付单保持一致。
