## 验收步骤

1. 启动本地 `Docker`（容器工具）依赖和后端，后端端口为 8080。
2. 重新导入最新演示数据，确认中文知识片段写入正常。
3. 调用 `/api/v1/knowledge/vector/rebuild` 重建 `v1`（知识版本）向量。
4. 调用 `/api/v1/agent/guide/stream` 执行真实流式导购，确认返回知识依据、商品卡片和 `decisionId`（导购决策编号）。
5. 使用 `decisionId`（导购决策编号）发起拼团锁单。
6. 调用 `/api/v1/payment/create` 创建支付单，并调用 `/api/v1/payment/webhook` 发送支付回调和重复回调。
7. 调用 `/api/v1/evaluate/guide/run` 执行 50 条评测用例。
8. 采集 `/actuator/prometheus`（指标端点）中的向量、工具、导购和支付指标。
