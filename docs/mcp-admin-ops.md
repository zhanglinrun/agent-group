# MCP 管理运维能力

当前项目在原有 `MCP`（模型上下文协议）服务注册、启停、发现工具和缓存工具基础上，继续补齐了运营侧可验证能力。

## 新增能力

- 健康检查：读取服务数量、启用服务数量、工具数量、可用服务数量和降级服务数量。
- 配置导出：导出当前 `MCP`（模型上下文协议）注册表快照，包含服务、工具缓存和发现时间。
- 配置导入：支持把导出的快照重新导入，默认合并当前配置；传入 `replace=true`（覆盖导入）时会替换当前配置。
- 工具试调用：运营端可以选择已缓存工具，填写 `arguments`（调用参数）后直接验证真实返回。

## 接口

- `GET /api/v1/mcp/admin/health`（健康检查）
- `GET /api/v1/mcp/admin/export`（导出配置）
- `POST /api/v1/mcp/admin/import`（导入配置）
- `POST /api/v1/mcp/admin/tools/{toolName}/call`（工具试调用）

这块能力主要用于把参考项目里的工具管理体验迁移到当前项目，使 `Agent`（智能体）工具接入不只停留在代码层，而是可以在前端管理面板里直接验证。
